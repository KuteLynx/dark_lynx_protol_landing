# Internationalization — DarkLynxProtocol

## Overview

Spanish-first i18n with English as secondary language. The site defaults to Spanish for all users, with explicit opt-in to English via URL parameter (`?lang=en`) or language toggle.

## Locale Initialization Priority

1. URL query param `?lang=en` or `?lang=es`
2. `localStorage` saved preference
3. Browser default → **es** (always defaults to Spanish)

## Implementation

File: `src/lib/i18n/state.svelte.ts`

- Reactive `locale` object with `.current` getter/setter
- `$state` rune for reactivity
- On set: persists to `localStorage`, updates `<html lang="...">` attribute
- `t(key)` function: returns translated string for current locale
- `tObj<T>(key)` function: returns complex translated objects (arrays of objects)
- Falls back to the key if translation is missing (console warning)

## Translation Files

| File | Language |
|---|---|
| `src/lib/i18n/es.json` | Spanish (primary, most complete) |
| `src/lib/i18n/en.json` | English (secondary) |

Translation structure mirrors the component hierarchy:
- `nav.*` — Navigation labels
- `seo.*` — Per-page SEO meta
- `cta.*` — Call-to-action labels
- `footer.*` — Footer content
- `home.*` — Home page sections
- `services.*` — Services page
- `philosophy.*` — Philosophy page
- `about.*` — About page
- `contact.*` — Contact form
- `journal.*` — Journal page
- `landingPages.*` — Landing pages sub-page

## Language Toggle

Component: `src/lib/components/ui/LanguageToggle.svelte`

- Toggles between `es` and `en`
- Uses `locale.current` setter
- Typically placed in navbar
